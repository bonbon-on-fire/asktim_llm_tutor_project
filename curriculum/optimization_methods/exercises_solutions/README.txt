Graded-exercise solutions / reference answers for 15.C57 Optimization.

exercise_solution_<N>.txt and would mirror exercises/exercise_<N>.txt one-to-one
by number.

No worked-solution files are shipped for this course yet. Official answer keys
have not been provided, and this course does NOT fabricate them: an invented
solution risks steering a student toward a wrong truth value, a wrong
formulation, or a wrong numeric result, which is worse than having no key at all.
When an official solution key is added, drop it in here as
exercise_solution_<N>.txt.
