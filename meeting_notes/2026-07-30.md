### Matt's thoughts

- If I have to create a new chat each time, there should be a reminder or something that says "It looks like you are asking about a different problem. Please create a new chat so I can support with that" or something. Otherwise I think they are going to get frustrated and leave once they have to start over.
- Window is too short to reliably help solve the problem. If I got 1 and then started a second and it shut off, I would leave and go to chat.
- Not enough of a context window to support problems.

## Decisions

- Surface the conversation cap to the team so we can evaluate whether it's set appropriately for real tutoring sessions.
- Add a proactive "looks like a new problem — start a new chat" nudge rather than relying on the learner to hit the cap and start over.
- Keep improving content connections (KCD and recitations) as a priority — video linking is on the right track but recitation/KCD routing still needs work.
