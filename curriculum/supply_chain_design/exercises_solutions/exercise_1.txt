Graded Assignment 1: Locky Locke Inc.

Part 0 (ungraded, 0 points — model setup check; solution shown by the course)
Correct answers:
  - Total weekly cost with all 12 decision variables set to 1: 390
  - LHS of the supply constraint for Supplier 1: 3
  - LHS of the demand constraint for Factory 1: 4
Explanation: This is a purchasing problem, but the network model is set up exactly
like a distribution problem. With "1" in each of the 12 decision variables (each of
the 3 factories buys 1 case from each of the 4 suppliers), total cost should be
$390 — if not, check the SUMPRODUCT cell references. Each supplier's supply-
constraint LHS = 3 (three factories each buy 1 case), and there are 4 supply
constraints. Each factory's demand-constraint LHS = 4 (four suppliers each ship 1
case), and there are 3 demand constraints. In Solver, set Objective = total cost,
Changing Cells = the decision variables, include all constraints, and use Simplex.
