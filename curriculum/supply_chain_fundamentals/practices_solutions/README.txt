Practice-problem solutions / explanations for MIT CTL.SC1x Supply Chain Fundamentals.

These are TUTOR-ONLY reference material, captured from the course's ungraded
practice problems (shown to students only after they attempt each problem and
click "Show Answer" / "Explanation"). Each solution is named
practice_solution_<N>.txt and mirrors practices/practice_<N>.txt one-to-one by
week number.

IMPORTANT: These files must NOT be folded into the student-facing practice text.
They are intended for the tutor's "correct-answer" context channel only. Leaking
them into practice prompt text would defeat the tutor's Socratic design.

Coverage note: Week 2 practice problems are distributed only as image
screenshots in the source materials (no extractable text), so Week 2 has no
practice_2 / practice_solution_2 file yet. Add them once a text version is
available (e.g. pulled from the live course).
